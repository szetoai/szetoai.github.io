### What I Learned

- **Full Stack Development**: This was my first experience with live hosting a website with so many users, so creating a full stack app that was able to handle that stress was quite a learning curve. Hosting on Vercel was new to me as well!

- **Database Querying**: With such a large scale database like Northeastern's courses, learning how to properly query and call the University API was tricky.

- **Design/Figma**: This was also my first time working with a design team and figma! Following plans made by designers made the programming process easier, but also introduced challenges of converting figma designs into actual code.
